# Creative tools

El inventario del entorno creativo se consulta con:

    one-creative-status

Las aplicaciones Flatpak se ejecutan mediante wrappers one-* ubicados en ~/.local/bin.

Ejemplos:

    one-inkscape personaje.svg
    one-krita boceto.kra
    one-blender --background escena.blend --python render.py
    one-gimp --help

Ver docs/CREATIVE_TOOLCHAIN.md para el flujo y la política de assets.
