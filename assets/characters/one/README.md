# ONE Character Kit

Directorio canónico de todos los recursos visuales del personaje ONE utilizados en los laboratorios de estudio.

## Regla de persistencia

Un recurso creativo no se considera terminado, aprobado ni disponible para integración hasta que:

1. exista físicamente dentro de este directorio o de otro path documentado de genai-fde-lab;
2. esté versionado por Git;
3. tenga un propósito y origen identificables;
4. si es un asset final, haya pasado por el toolchain creativo local.

Las imágenes generadas por IA son referencias de ideación, no assets finales. Si una referencia generada se adopta para el trabajo, también debe conservarse en `references/` para garantizar trazabilidad.

## Estructura

- `references/`: referencias conceptuales aprobadas y variantes relevantes.
- `source/raster/`: fuentes editables raster.
- `source/vector/`: fuente vectorial maestra.
- `source/animation/`: proyectos de animación/rig.
- `components/`: piezas intercambiables del personaje.
- `expressions/`: composiciones de expresión.
- `poses/`: poses reutilizables.
- `exports/`: artefactos derivados para integración web.
- `CHARACTER_SPEC.md`: fuente de verdad visual y de movimiento.
