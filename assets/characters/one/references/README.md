# Referencias visuales de ONE

Estas imágenes son referencias de ideación conservadas para trazabilidad del Character Kit de los laboratorios.

- `concept-a.webp`: alternativa A, no seleccionada.
- `concept-b-selected.webp`: **dirección visual seleccionada**.
- `concept-c.webp`: alternativa C, no seleccionada.
- `character-kit-v1.webp`: primera lámina de desglose derivada del Concepto B.

Estas referencias no son assets finales de producción. Desde la aprobación del Concepto B, el personaje se reconstruye con el toolchain creativo local como SVG y componentes editables. La continuidad visual no debe depender de regeneraciones con IA.

Las copias WebP están normalizadas para mantener las referencias dentro del repositorio. Concepto B y Character Kit se conservan a mayor resolución relativa por ser las fuentes activas de reconstrucción.

Ver `../CHARACTER_SPEC.md`.


## Estado de integridad

Las copias WebP persistidas desde la conversación no superaron la decodificación local con FFmpeg/Pillow el 2026-10-03. Se conservan únicamente como evidencia de trazabilidad, pero **no se consideran fuentes raster válidas de producción**. La dirección visual aprobada sigue siendo Concepto B y el Character Kit visibles en la conversación hasta disponer de copias decodificables.
