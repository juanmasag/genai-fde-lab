# Contributing

Este repositorio usa una disciplina de aprendizaje basada en evidencia.

Para cerrar un laboratorio:

1. Implementar en una branch lab/XX-*.
2. Agregar tests y documentación.
3. Registrar decisiones relevantes.
4. Abrir PR con evidencia de ejecución.
5. No marcar como aprendido algo que sólo fue generado por un agente sin revisión y explicación propia.

Los agentes de IA pueden acelerar implementación, debugging y documentación, pero el objetivo del repositorio es consolidar comprensión humana verificable.
