# Contributing

Este repositorio usa una disciplina de aprendizaje basada en evidencia.

Para cerrar un laboratorio:

1. Implementar en una branch lab/XX-*.
2. Agregar tests y documentación.
3. Registrar decisiones relevantes.
4. Abrir PR con evidencia de ejecución.
5. No marcar como aprendido algo que sólo fue generado por un agente sin revisión y explicación propia.

Los agentes de IA pueden acelerar implementación, debugging y documentación, pero el objetivo del repositorio es consolidar comprensión humana verificable.

## Regla de alcance entre repositorios

- No modificar el proyecto ONE desde este repositorio.
- No modificar ningún otro repositorio sin confirmación explícita del usuario para esa acción.
- Se puede consultar material externo en modo lectura si hace falta contexto.
- Cualquier escritura, commit, push, creación, edición, movimiento o eliminación fuera de genai-fde-lab requiere autorización previa.
- Las herramientas creativas y el personaje desarrollados aquí se incorporan únicamente a los laboratorios de estudio, salvo autorización expresa.

Ver también AGENTS.md, que establece esta regla como instrucción obligatoria para agentes y automatizaciones.
